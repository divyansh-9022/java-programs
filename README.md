# Java Programs

A collection of Java programs created to practice programming fundamentals,
problem-solving, and basic real-world applications.

## 📚 Programs

| Program | Concepts |
|---|---|
| Calculator | Methods, Switch, User Input |
| Number Analyzer | Loops, Methods, Conditions |
| Employee Salary Calculator | Variables, Calculations |
| Expense Tracker | ArrayList, Methods, CRUD |

## 🛠️ Technologies

- Java
- Java Collections
- Object-Oriented Programming
- IntelliJ IDEA

## 🎯 Learning Goals

- Improve Java programming fundamentals
- Practice problem-solving
- Understand methods and control statements
- Learn Java Collections
- Build small console-based applications
